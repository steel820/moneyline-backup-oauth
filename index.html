Personal backup utility

Moneyline Backup

This page describes a personal-use Google Drive authorization application. It is used by its owner to store and recover backups of privately operated software and data.

Not a public service. This application is for the owner's own Google account. It does not offer public registration, hosted betting predictions, or access to backup contents.

How the backup works

The owner uses rclone to connect to Google Drive and restic to create encrypted backup repositories. Backup contents are encrypted locally before transfer to Google Drive.

Google Drive permissions

The authorization requests Google's drive.file permission, which limits access to files the application creates or opens. The application does not request unrestricted access to other Drive files.

Privacy

No passwords, access tokens, backup passphrases, or backup files are published on this website. Read the Privacy Policy for details on data access and retention.
