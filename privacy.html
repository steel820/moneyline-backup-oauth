Personal backup utility

Privacy Policy

Moneyline Backup · Effective October 26, 2026

Purpose

Moneyline Backup is a personally operated desktop backup workflow. Its Google OAuth authorization allows the owner to use rclone with the owner's Google Drive account for private backup storage and recovery. It is not offered as a public service.

Google data accessed

The OAuth client requests the drive.file scope. That scope permits the application to create and manage files it creates or opens through the application, rather than unrestricted access to unrelated files in Google Drive. The workflow may access file names, metadata, contents and storage quota information needed to upload, list, verify and restore its own backups.

How the data is used

Google Drive access is used solely for backup storage, integrity checking and recovery initiated by the owner. Backup repository contents are encrypted locally using restic before upload. A non-secret recovery guide may also be stored as a readable document. The application does not use Google data for advertising or profiling.

Storage and security

OAuth credentials are stored locally in a user-restricted rclone configuration on the owner's computer. Backup encryption passphrases and OAuth tokens are not published on this website or committed to this public repository. Backup files are stored in the owner's Google Drive account.

Sharing and website data

The owner does not sell Google user data or share it with advertisers or data brokers. Google Drive hosts backup files at the owner's direction. This informational website has no account-registration form, tracking script, custom analytics or advertising cookies. GitHub Pages hosts the website and may process basic access information under GitHub's own policies.

Retention and deletion

Backups remain in the owner's Google Drive until removed under the owner's backup retention and deletion process. The owner can revoke this application's Google access through Google Account security settings. Revoking access stops future authorization but does not itself delete files already stored in Google Drive; those files must be deleted separately.

Changes and contact

This policy may be updated if the personal backup workflow changes. The effective date above will be revised when material changes are made. For privacy questions, contact the operator through the steel820 GitHub profile.
